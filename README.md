# WinSam Crochet

한국 사용자를 위한 Ravelry 도안 탐색 서비스. Next.js 16 / React 19 / TypeScript.

## 실행

Node.js 24 이상(내장 TypeScript 지원 테스트 기준), pnpm을 사용합니다.

```sh
pnpm install
```

`.env.local`에 Ravelry 읽기 API 인증 정보를 설정하세요. 이 파일은 커밋하지 않습니다.

```dotenv
RAVELRY_USER_ID=your-api-user
RAVELRY_API_KEY=your-api-key
YOUTUBE_API_KEY=your-youtube-data-api-key
```

```sh
pnpm dev
pnpm build
pnpm test
pnpm check:api
```

`check:api`는 실제 Ravelry에 읽기 요청을 보내므로 네트워크와 인증 정보가 필요합니다. 기본 단위 테스트는 네트워크를 사용하지 않습니다.

## 화면

- `/`: 한국어 용어 검색, 공예·카테고리·언어·도안 형식·난이도·제공 방식 필터.
- `/pattern/[id]`: 준비물, 언어·형식, 무료/구매 경로, 원문 소개와 번역기 연결, 완성작 원문 링크.
- 상세 하단 YouTube 영상: 작가·도안명·특징으로 검색하고 한국어 정보를 우선해 최대 5개 표시합니다. 카드에서 YouTube로 이동합니다.
- `/saved`: 로그인 없이 브라우저에 저장하는 찜·최근 본 도안.
- `/guide`: 실·바늘·게이지·US/UK 코바늘 약어 길잡이.
- `/free-patterns`: 레이블리 무료 도안 모음. 코바늘·대바늘, 한국어·기호·쉬운 도안 조건과 페이지 이동, 무료 제공처 이용 안내.

## 검색 노출

- 홈·검색 결과·도안 상세·무료 도안·길잡이에 페이지별 제목, 설명, canonical과 Open Graph URL을 제공합니다. 상세의 `from`은 대표 URL에서 제외합니다.
- `/robots.txt`는 수집을 허용하고 `/sitemap.xml` 위치를 안내합니다. 사이트맵에는 홈·무료 도안·길잡이의 고정 주소가 들어가며, 개별 도안은 목록의 서버 렌더링 링크로 발견할 수 있습니다.
- 브라우저별 개인 목록인 `/saved`는 `noindex, follow`를 사용합니다.
- 배포 후 네이버 서치어드바이저에 `https://crochet.winsam.xyz/sitemap.xml`을 제출하세요. 코드 변경만으로 제출되지는 않습니다.

## 데이터 처리

- API 인증은 `server-only` 모듈에서만 사용합니다.
- 검색 12건을 가져온 뒤 상세 정보를 일괄 조회합니다. 개별 카드마다 요청하지 않습니다.
- 검색·상세 캐시는 1시간, 인기 목록은 10분입니다. 요청 제한 시간은 15초입니다.
- Ravelry 한국어 언어 코드는 `kr`입니다. `ko`는 실제 API에서 실패합니다.
- 낮은 난이도 필터는 `difficulties=1|2`입니다. `difficulty`는 필터로 작동하지 않았습니다.
- 일괄 상세 조회의 `ids`는 공백으로 구분한 뒤 URL 인코딩해야 합니다. 리터럴 `+`를 `%2B`로 인코딩하면 일부만 반환될 수 있습니다.
- `free=true`여도 `download_location.free=false`일 수 있습니다. 무료 웹 제공과 유료 파일 구매를 구분하고, 이 경우 무료 안내 링크를 먼저 보여줍니다.
- 등록되지 않은 언어·바늘·난이도를 추정하지 않습니다. 난이도 평가는 작가의 등급과 별개입니다.
- 한국어 검색은 용어 사전 기반입니다. 임의의 문장을 완전히 번역하는 기능은 아닙니다.
- 설명 번역은 외부 Google Translate 연결입니다. 도안 파일 전체 번역·국내 실 자동 추천은 제공하지 않습니다.
- 찜·최근 본 기록은 이 브라우저의 localStorage에만 저장됩니다. 외부 다운로드 완료 여부를 자동 추적하지 않습니다.

## YouTube 관련 영상

- Google Cloud에서 YouTube Data API v3를 활성화하고 서버 환경 변수 `YOUTUBE_API_KEY`를 설정합니다. 배포 환경에도 별도로 설정해야 합니다. `NEXT_PUBLIC_` 접두사를 사용하지 않습니다.
- 작가명과 도안 특징을 조합합니다. 예: `Lucy of Attic24` / `Neat Ripple` / `throw` → `Attic24 물결 담요`. 알려진 특징 번역이 없으면 원래 도안명을 유지합니다.
- 검색당 10개를 받고 한국어 관련 결과가 3개 미만이면 한국어 검색으로 한 번 더 탐색합니다. 캐시가 없는 경우 도안당 최대 검색 2회, 검색별 영상 상세 일괄 조회 1회입니다.
- 성공 응답과 빈 검색 결과는 Next.js Data Cache로 7일간 재사용합니다. 만료 후 갱신과 동시 요청에서는 추가 호출이 발생할 수 있습니다. 캐시 유지 여부는 배포 플랫폼 설정에 따릅니다.
- 관련성은 제목·설명·언어 메타데이터 기반입니다. 도안명 언급과 비슷한 작품·기법을 구분하며 동일 도안이나 공식 강좌라고 단정하지 않습니다. 한국어 음성 메타데이터가 없는 경우 한국어 제목·설명으로 표시합니다.
- 관련 결과가 적으면 1~2개만, 없으면 안내와 직접 검색 링크를 표시합니다. 인증·할당량·네트워크 오류가 도안 상세를 막지 않습니다. 403/429 발생 시 해당 서버 인스턴스는 1시간 호출을 중단합니다. 이는 전체 배포의 일일 호출 제한을 보장하지 않습니다.
- 재검증: `node scripts/check-youtube.mjs 'Attic24 물결 담요'` (검색 1회 + 영상 상세 조회 최대 1회). 키는 출력하지 않습니다.

## 확인 사항

단위 테스트는 한국어 검색 해석, 무료 웹/유료 파일 혼합 사례, 누락 링크, 안전한 URL, 길이 변환과 한국어 언어 코드를 확인합니다. 실제 API 검증 스크립트는 한국어·차트·난이도·무료 필터와 다건 상세 응답을 확인합니다.
